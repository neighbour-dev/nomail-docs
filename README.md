# NoMail 文档

NoMail 是一个通知收件箱，由 App 和可自托管的服务端组成，将不同平台的事件与通知汇集起来，方便集中查看和管理。

本仓库是 NoMail 的文档站，基于 VitePress 构建，以产品使用和实际任务为主线，同时提供面向后端与 App 开发的接口和平台协议参考。

**文档地址：[English](https://nomail.sg) · [简体中文](https://nomail.sg/zh/)**

## 文档内容

| 目录 | 内容 |
|---|---|
| `guide/` | 英文产品介绍、自托管服务安装、平台接入与密钥管理 |
| `reference/` | 英文上游平台 Webhook 协议与投递规则 |
| `research/` | 英文产品与竞品研究 |
| `zh/` | 与英文页面同路径的简体中文文档 |

## 文档维护原则

- 产品文档持续跟随[最新正式发布版](https://github.com/neighbour-dev/nomail-api/releases/latest)，不固定到某个版本。更新前核对最新 GitHub Release、对应标签代码和该版本的 OpenAPI 附件，不将 `main` 或 Unreleased 功能当成现有能力。客户端能力需另行核对其发布版本，不能从后端支持推断。
- 每页只负责明确主题：安装总览维护通用配置，各部署页维护运行方式特有操作，升级页维护版本兼容与迁移前置条件，接入页维护产品支持范围和操作流程，平台协议页仅维护上游规则。NoMail HTTP 契约引用正式发布版的 OpenAPI 附件，不另行扩展 API 参考页面。
- 同一规则只在所属页面完整说明，其他页面通过链接引用，不复制完整段落。新增内容同步中英文页面、目录入口和相关链接。
- 通用安装页面与 API 附件链接使用最新版入口，镜像默认使用 `latest`，源码使用最新正式版标签；仅在历史迁移条件或兼容性说明中保留具体版本号。新版本发布后仍需重新核对行为并同步文档，不能只依赖最新版链接。
