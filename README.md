# NoMail 文档

NoMail 是一个通知收件箱，由 App 和可自托管的服务端组成，将不同平台的事件与通知汇集起来，方便集中查看和管理。

本仓库是 NoMail 的文档站，基于 VitePress 构建，以产品使用和实际任务为主线，同时提供面向后端与 App 开发的接口和平台协议参考。

**文档地址：[English](https://nomail.sg) · [简体中文](https://nomail.sg/zh/)**

## 文档内容

| 目录 | 内容 |
|---|---|
| `guide/` | 英文产品介绍、自托管服务安装、平台接入与密钥管理 |
| `reference/` | 英文平台 Webhook 协议与投递规则 |
| `research/` | 英文产品与竞品研究 |
| `zh/` | 与英文页面同路径的简体中文文档 |
