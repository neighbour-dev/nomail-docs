# NoMail platform protocol reference

This section describes source platforms' upstream Webhook protocols. It does not define NoMail's own API or promise support for every upstream capability.

## Upstream platform protocols

| Topic | Entry point |
|---|---|
| Platforms, encodings, and response requirements | [Platform Webhook protocol index](webhook-platform-reference-2026-10-30.md) |
| Field requirements, version evidence, and algorithm notation | [How to read the contracts](webhook-contract-conventions.md) |

Each platform page describes upstream request identification, source authentication, body structures, response contracts, and delivery semantics. These pages do not define NoMail's supported feature set or API. Product support and setup workflow belong to [Connect notification sources](../guide/sources.md).

If you only need to connect sources rather than implement protocols, start with the [user guide](../guide/index.md).
